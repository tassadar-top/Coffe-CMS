# Coffee CMS

Modular PHP CMS with one shared core and switchable business profiles. The current baseline includes `coffee_shop`, `barber_shop`, `beauty_services`, and `shawarma_shop`.

## What is already implemented

- shared CMS core with modular business profiles
- profile configs in `config/business_profiles`
- theme configs in `config/themes`
- profile-based module registry and profile-aware admin navigation
- shared order module and shared customer account module
- universal catalog item flags: `is_showcase` and `is_purchasable`
- admin authentication with a custom admin URL
- fake `/admin` honeypot with logging
- page, catalog, and promotion editing with browser-based image uploads
- theme switching with previews from the admin panel
- theme-specific public templates for `home`, `menu`, `services`, `portfolio`, and `reviews`
- SEO section, `robots.txt`, and `sitemap.xml`

## Installation

1. Create a database named `coffee_cms`.
2. Import [database/install.sql](/C:/Users/admin4F/Documents/Coffe%20CMS/database/install.sql).
3. Import [database/seed.sql](/C:/Users/admin4F/Documents/Coffe%20CMS/database/seed.sql).
4. Update [config/database.php](/C:/Users/admin4F/Documents/Coffe%20CMS/config/database.php).
5. Update [config/config.php](/C:/Users/admin4F/Documents/Coffe%20CMS/config/config.php).
6. Select the active `business_profile` in [config/config.php](/C:/Users/admin4F/Documents/Coffe%20CMS/config/config.php).
7. Make sure the selected theme belongs to that profile.
8. Point your web server document root to [public](/C:/Users/admin4F/Documents/Coffe%20CMS/public).
9. Replace the seeded admin password hash with your own value generated by `password_hash(...)`.

## Business profiles

- `coffee_shop`: catalog, delivery placeholder, promotions, gallery, reviews, account, orders
- `barber_shop`: services, masters, booking, pricing, portfolio, reviews
- `beauty_services`: services, masters, booking, pricing, portfolio, reviews, account
- `shawarma_shop`: catalog, orders, account, promotions, gallery, reviews

## Catalog rules

- If `is_showcase = 1`, the item is visible on the storefront.
- If `is_purchasable = 1`, the item can be used in ordering flows.
- The same catalog model can be reused across coffee, shawarma, and future product-based profiles.
